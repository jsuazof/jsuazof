# Cloud Security Engineer | Infrastructure, Network & Systems Security | GCP

Cloud infrastructure and security professional based in Santiago, Chile, with 25+ years of experience across enterprise networks, systems, virtualization, storage, monitoring, and business continuity. I apply this operational foundation to cloud security engineering, helping organizations design, secure, and maintain reliable environments on Google Cloud Platform.
